# แดนชำระ — กฎ ๙ ข้อของบ้านมรดก

Psychological horror RPG แบบ top‑down 2D ที่เล่นบนเว็บเบราว์เซอร์ได้ทันที ยาวประมาณ 45–60 นาที มี 10 บทและ 2 ตอนจบ

## วิธีเล่น
เปิด `index.html` ผ่านเว็บเซิร์ฟเวอร์แบบ static ตัวไหนก็ได้ ไม่ต้อง build
```bash
python3 -m http.server 8000
```
แล้วเข้าที่ http://localhost:8000 (ใช้กับ GitHub Pages ได้ทันที)

| ปุ่ม | การทำงาน |
|---|---|
| ลูกศร / WASD | เดิน |
| E / Space / Enter | ตรวจสอบ / ยืนยัน |
| J (หรือ Tab) | สมุดกฎ · ของ · ความทรงจำ |
| I | ของที่ถือ |
| Esc | เมนูหยุดชั่วคราว |

บนมือถือจะมีปุ่มสัมผัสให้อัตโนมัติ เกมจะบันทึกอัตโนมัติเมื่อเริ่มแต่ละบท (เก็บใน localStorage)

## โครงสร้าง
- `js/engine.js` — แผนที่แบบไทล์ การรับปุ่ม บทสนทนา แสงเงา และเอฟเฟกต์
- `js/sprites.js` — ภาพพิกเซลที่วาดด้วยโค้ดทั้งหมด
- `js/audio.js` — เสียงสังเคราะห์ด้วย WebAudio (ไม่มีไฟล์เสียงภายนอก)
- `js/chapters.js` — เนื้อเรื่อง แผนที่ และปริศนาของทั้ง 10 บท
- `js/main.js` — หน้าแรก การบันทึก สมุด เกมโอเวอร์ ตอนจบ และเครดิต

ตัวช่วยทดสอบ: เติม `?ch=N` ต่อท้าย URL เพื่อข้ามไปบทที่ N (1–10)
